# 0.13.0：质量修复与浏览器直链下载

## 主要变化

- Emby 网关删除 IP/UA 免凭据缓存，改为媒体项和媒体源绑定的十分钟签名；伪造转发头无法获取播放权限。
- 保存、浏览器下载、STRM 播放使用不同用途的凭据。操作签名绑定资源并自动到期。
- 后台任务在释放任务锁后注册 Future 回调，避免快速任务自锁。重载配置时必须等待旧任务停止；超时会明确拒绝重载，避免新旧组件并行写入。
- STRM 文件名增加稳定资源标识，长中文名称保留标识。重建时只移除数据库登记且内容仍属于该资源的旧 STRM。不同来源不再覆盖同一播放入口。
- 旧直链下载模式的目标文件也按资源区分；临时文件校验范围和长度后以不覆盖既有文件的方式发布。修复失效直链刷新、流中断重试、未构建剧集选集，以及暂停后快速恢复导致的重复线程。
- 普通表每轮读取最新工作表尺寸，新增分页不会被旧行数截断。继续保留页数据与检查点的事务边界。
- 刮削复用需要成功标记和完整文件集合；残留海报不再代表成功。新增剧集文件会触发补全。并发刮削完成后重新结算空间占用。
- 错误 file_id 等请求错误不再将有效分享改为永久无效。
- 清空功能与任务提交互斥，拒绝清理仍在使用的离线记录；按文件归属与内容摘要删除，保留用户文件及修改过的文件。
- 搜索桥兼容新版 `app/chain/search/` 布局；网关路径/诊断缓存有容量限制，资源锁使用弱引用释放空闲项。

## 浏览器下载

默认开启“使用浏览器下载视频”，只针对本插件的搜索结果，不接管其他站点。电影直接解析并返回 302；电视剧提供文件选择；磁力/ED2K 在 115 云端离线完成后返回直链。MoviePilot 不创建下载器任务，不传输视频正文。

**原生卡片的点击行为需要浏览器侧适配。**仓库提供[用户脚本和 V3 前端补丁](../../integrations/README.md)，升级插件不会自动安装它们。未安装适配时，可使用 `ⓘ` 详情页中的浏览器下载链接。浏览器下载完成不触发 MoviePilot 下载器的进度报告和自动整理。

## 升级注意

- 更新后重新搜索，获取新的短时保存和下载链接。旧的全局播放 token 保存链接会被拒绝，但现有 STRM 播放链接继续有效。
- 正在播放的网关客户端应重新获取 PlaybackInfo；单凭 IP/UA 的旧请求不再授权。
- 输出根目录中会出现 `.tencentdoc115-owned.json` 归属清单。不要手工删除或修改。清空时内容发生变化的文件会保留。
- 无法可靠推断归属的旧版元数据不会被自动纳入删除清单。旧资源重建后会登记新输出；此前已经被覆盖的文件无法仅靠升级恢复。
- 元数据完整性使用媒体目录中的 `.tencentdoc115-scrape.json` 成功标记；旧版没有标记的目录会执行一次补全，保留可复用的现有元数据。
- 若希望沿用旧 MoviePilot 直链下载任务，关闭“使用浏览器下载视频”。已有下载文件不自动重命名或删除；旧版临时文件可能需要手工确认后处理。

仓库测试加载真实插件入口，以宿主替身和模拟网络边界隔离真实账户。新增回归涵盖审查复现、签名作用域/过期、HTTP 302、剧集选文件、清理归属和浏览器模式禁止创建下载任务。

```bash
python -m pytest plugins.v2/tencentdoc115library/tests -q
node --test integrations/test-browser-download.cjs
```

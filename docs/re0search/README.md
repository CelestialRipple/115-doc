# RE0 资源搜索 MoviePilot 插件

这是一个与腾讯文档影视库完全独立的 MoviePilot V2 插件原型

## 功能

- 使用 MoviePilot 元数据搜索选择 TMDB 电影或剧集
- 通过 MoviePilot 内置 CloakBrowser 登录并搜索 RE0 资源
- 识别 115、磁力和 ED2K 链接
- 免费或付费资源均要求用户逐条确认后才会解锁
- 可选每日自动签到
- 浏览器上下文固定在同一工作线程并复用，避免网页安全会话与 Cookie 分离
- 每次操作结束都会移除临时响应监听器，避免长期运行时累积回调
- 已解锁链接可选择直属文件夹和媒体类型，并交给腾讯文档115媒体库的公开自选导入入口

RE0 插件本身不会复制 115 解析、离线下载或 STRM 代码。保存媒体库是可选联动；未安装腾讯文档115媒体库时，仍可搜索、解锁并打开原始链接

## 配置

1. 安装后填写 RE0 用户名或邮箱与密码
2. 群晖套件保持“无头浏览器”开启
3. RE0 无法直连时可填写代理，例如 `socks5://192.168.5.194:7891`
4. 如需签到可打开“每日自动签到”，默认周期是每天 08:17
5. 保存配置后进入插件详情页，点击“打开搜索页面”

登录凭据只保存在 MoviePilot 插件配置中。插件复用同一个浏览器上下文，但不会把 Cookie 或已解锁链接写入日志

## 使用

先输入片名并选择正确的 MoviePilot TMDB 条目，再搜索 RE0 资源。资源所需积分无法可靠识别时，插件会拒绝解锁；识别成功后仍会弹出逐条确认，不存在后台自动扣分

点击“保存到媒体库”前可选择：

- 直属输出文件夹，例如 `RE0`、`RE0-电影` 或 `RE0-剧集`
- 电影、剧集或自动识别

保存功能要求“腾讯文档115媒体库”0.12.1 或更新版本正在运行。目标插件会在自己的后台队列中完成匿名 115 枚举、磁力或 ED2K 登记、MoviePilot 识别、刮削和 STRM 生成

## 限制

- 当前版本不做整站抓取，只处理用户主动选择的一部媒体和一条资源
- 出现验证码时无头登录会停止并诚实报错，不会尝试绕过验证码
- RE0 页面更新后可能需要同步更新资源卡片或按钮适配
- “打开链接”打开的是 RE0 返回的原始资源链接，不等同于 115 文件直链下载

# PanSou 聚合搜索 0.2.0

MoviePilot 原生“站点资源”搜索同时显示腾讯文档和 PanSou 结果。BT4G 默认提供一个带当前关键词的网页搜索入口，点击后打开新标签页。插件不请求 BT4G 页面，不回填结果，也不处理 Cloudflare 验证。

## 使用

1. 添加本仓库，安装并启用 **PanSou聚合搜索**。
2. 填写 PanSou 服务地址，可以是服务根地址、`/api` 或完整的 `/api/search` 地址。开启认证时填写 Bearer Token，或用户名和密码。
3. 根据需要限制网盘类型、搜索插件或 TG 频道；留空使用 PanSou 默认范围。
4. 在 MoviePilot 原生资源搜索输入片名。结果点击进入浏览器下载，右下角 `ⓘ` 打开资源详情并保存影视库。插件详情页也提供独立搜索页面。

**原生卡片点击需要前端适配**：后端插件无法单独改变 MoviePilot 的下载弹窗。可选择以下一种方式：

- 部署者在 MoviePilot 的 `public` 静态目录安装[页面适配脚本](../../integrations/install-browser-adapter.py)：`python3 integrations/install-browser-adapter.py /path/to/moviepilot/public`。脚本与同目录的 `moviepilot-browser-download.user.js` 一起使用，保留备份、可重复执行，无需重启。MoviePilot 更新覆盖前端后需重新执行。
- 浏览器安装[用户脚本](../../integrations/moviepilot-browser-download.user.js)，将匹配范围限制为自己的 MoviePilot 地址。
- 自行编译前端时使用[原生辅助函数](../../integrations/moviepilotBrowserDownload.ts)，在打开下载弹窗前调用它，返回 `true` 时结束该点击流程。

没有适配时可使用 `ⓘ` 中的“浏览器下载”按钮；不要把 `pansou://` 标记当成 torrent 链接交给下载器。适配脚本只接管这两个插件和 BT4G 入口，其他站点保留 MoviePilot 的行为。

## 下载与保存

| 结果 | 下载 | 保存影视库 |
| --- | --- | --- |
| 115 分享 | 列出视频，选择后返回302临时地址 | 复用腾讯文档插件的手动导入和刮削 |
| 磁力、ED2K | 复用115离线解析，完成后浏览器下载 | 复用手动导入，首次播放按既有规则离线 |
| 其他网盘 | 打开原始分享页，显示提取码 | 当前115接口不支持 |
| BT4G | 新标签页打开当前关键词的网页搜索 | 不适用 |

115 下载和保存依赖启用 **腾讯文档115媒体库 0.13.0+** 并配置有效115账号。解析保留浏览器 User-Agent。插件只返回302，不代理传输视频，也不创建 MoviePilot 下载器任务。浏览器收到视频后是下载还是播放取决于115响应和浏览器设置。

下载磁力、ED2K 时会创建115离线缓存。下载记录使用聚合插件独立的 `downloads.db`，不进入影视库构建队列；定时清理复用原插件的到期与目录归属检查。默认缓存保留时间沿用腾讯文档插件设置。停用聚合插件期间其清理任务也停止。

保存是明确的用户操作。腾讯文档插件忙于同步或刮削时，导入接口可能拒绝提交，页面会显示实际消息，稍后重试即可；聚合插件不会停止现有任务。

## 升级与限制

- 0.1.0 的 BT4G 结果助手、浏览器回传和代理选项已移除，可以卸载旧的 BT4G 用户脚本。
- 搜索结果最多200条 PanSou 资源，另加1个 BT4G 入口；签名操作链接和结果缓存最长保留1小时，过期后重新搜索。
- 搜索按链接去重，使用独立资源标记防止无 torrent 的网盘结果被丢弃。旧版兼容入口与腾讯文档站点共存；筛选掉聚合站点时不会强行添加结果。
- PanSou 请求有超时及4 MiB响应限制，不跟随认证重定向，不继承外部代理。单个来源失败不影响 BT4G 入口。
- 不保存 BT4G Cookie，不把 MoviePilot 密钥传给外部网页。接口参数、分享标题和提取码按不可信输入处理。

测试覆盖原生入口共存、唯一资源标记、鉴权和过期签名、真实 SQLite 外键、下载记录隔离、文件选择、浏览器UA、302、导入参数和前端点击范围。生产联调已验证原生列表同时出现文档、PanSou 和 BT4G；不把模拟115响应的自动测试等同于所有分享的实际下载成功。

# PanSou 聚合搜索 0.1.0

独立 MoviePilot 插件，将自建 PanSou 与 BT4G 资源加入 MoviePilot 搜索。搜索只读；只有用户点击“添加到115媒体库”才会调用腾讯文档115媒体库的导入功能。

## 安装与配置

1. 将 `https://github.com/CelestialRipple/115-doc/` 添加到 MoviePilot 插件仓库，刷新后安装“PanSou聚合搜索”。
2. 填写 PanSou 服务地址，例如 `http://192.168.1.10:实际端口`。支持站点根地址、`/api` 或完整 `/api/search` 地址。群晖 DSM 的 `5001` 是管理端口，不一定是 PanSou 服务端口。
3. PanSou 开启认证时，填写它自己的用户名和密码，或 Bearer Token。此处不是 DSM 登录账号。Token 优先于账号密码。
4. 可填写 `cloud_types`：`115,magnet,ed2k` 只保留可与115媒体库联动的资源；留空聚合所有网盘。也可限定 PanSou 插件或 TG 频道。
5. 启用插件和所需来源。BT4G 默认地址为 `https://bt4gprx.com`。可选代理只作用于 BT4G，PanSou 内网请求不使用系统代理。
6. 从 MoviePilot 原生搜索查看结果，或从插件详情页打开“聚合搜索与BT4G验证”。原生结果右下角 `ⓘ` 打开资源操作页。

不需要重启 MoviePilot 或媒体库服务。若正在同步/刮削，仅安装这个独立插件即可；不需要重载腾讯文档115媒体库插件。

## BT4G 真人验证

BT4G 可在搜索页、详情页甚至翻页时重新要求验证。浏览器通过验证不代表 NAS 后台请求也能通过：IP、浏览器和会话可能不同。因此插件不搬运 `cf_clearance`，不自动点击验证码，也不把验证页当成“搜索结果为空”。

在用户自己的浏览器中：

1. 用 Tampermonkey 等脚本管理器安装[BT4G结果助手](../../integrations/bt4g-results.user.js)，默认只作用于 `https://bt4gprx.com/*`。使用其他 BT4G 域名时需同时调整脚本的匹配地址和插件设置。
2. 在插件聚合搜索页搜索片名，点击“打开 BT4G，验证并带回结果”。
3. 出现 Cloudflare 验证时，用户手动完成。
4. 点击右下角助手的“带回 MoviePilot”。当前页结果进入插件缓存，随后相同关键词的 MoviePilot 搜索也能看到它们。如果 MoviePilot 自身缓存了旧结果，请重新发起搜索。
5. 若浏览器因跨站隔离使窗口回传不可用，点击“显示可复制 JSON”，将内容粘贴到聚合搜索页的手动导入区域。

只回传当前用户打开的页面，不自动遍历全部详情页。搜索列表里的 `/magnet/不透明ID` 只是 BT4G 详情页，不是磁力哈希；助手会保留详情页供打开。在同一个 BT4G 标签页进入某一资源详情页后，再点击“带回 MoviePilot”，助手可以从页面公开的下载按钮提取真实哈希并生成磁力链接。无需访问按钮指向的外部下载站。再次验证时仍由用户完成。

助手不读取或发送 Cookie、MoviePilot 登录令牌和 DSM 凭据。窗口回传校验来源、发起窗口和本次随机标识；回传资源在服务端再次校验。浏览器上下文和结果缓存为临时数据，重启或超时后需重新搜索。

## 打开、下载与媒体库联动

| 结果类型 | 支持操作 |
| --- | --- |
| 115 分享 | 打开原始分享、复制提取码、确认导入115媒体库 |
| 磁力、ED2K | 复制链接、确认导入115媒体库；首次播放由115媒体库进行云端离线 |
| 百度、夸克、阿里等其他网盘 | 打开分享页、查看提取码；不自动转存或解析视频直链 |
| BT4G 列表结果 | 打开详情页；助手在用户验证后可提取真实磁力 |

磁力结果保留真实 `enclosure`，MoviePilot 原生卡片的常规下载动作仍遵循 MoviePilot 的下载器配置；不希望创建下载器任务时请使用 `ⓘ` 或插件搜索页的资源操作入口。其他网盘和 BT4G 详情页不伪装成 torrent 下载链接。

聚合插件不会把任意网盘变成视频直链。115 媒体库导入完成后，可使用该插件 0.13.0 的浏览器下载功能。磁力和 ED2K 需要115云端离线，其他网盘暂不支持这条路径。

保存到媒体库复用已运行的 `TencentDoc115Library.import_manual_resources`，默认为“聚合搜索”直属文件夹与自动电影/剧集识别。不会自动选择其他搜索结果批量入库。

## 兼容性、限流与验证

- 新版 MoviePilot 使用原生独立插件搜索入口；旧版使用仅搜索链可见的虚拟来源，在调用网络索引器前直接处理。现有115虚拟来源与真实 PT 站点保留原行为。
- 旧版若显式只选择某些 PT 站点、或设置了站点白名单，宿主可能过滤掉虚拟来源；此时用“全部站点”或插件搜索页。
- 每个实例最多两个来源并发请求。失败来源会显示错误，其他来源仍返回结果；搜索缓存默认120秒、最多50个关键词，资源操作链接有效期1小时，浏览器回传结果保留30分钟。过期需重新搜索。
- PanSou 登录每次未命中缓存时获取新 Token；登录失败、API地址错误和解析失败有独立反馈。不会把原始异常里的账号、认证地址写进日志。
- HTTP 响应限制4 MiB。PanSou 不跟随重定向以免泄露认证信息；BT4G 最多跟随3次同源重定向。
- 已用用户手动验证后的 BT4G 真实搜索/详情 DOM 校验当前 `notion-list-item` 与 `notion-detail-title` 结构。网页后续改版可能需要更新。
- 自动测试覆盖正常/异常API、鉴权、失效签名、恶意链接、来源隔离、真实BT4G结构、浏览器回传及旧版115入口共存。不将这些测试等同于用户 NAS 的生产联调。

PanSou API 字段以[官方文档](https://github.com/fish2018/pansou#搜索api)为依据。本插件不包含用户的 NAS 地址、账号密码或 PanSou 私有配置。

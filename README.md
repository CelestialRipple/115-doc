# 115-doc

这个插件市场目前包含三个相互独立的 MoviePilot V2/V3 插件

- “腾讯文档115媒体库”负责同步普通表、智能表和自选资源，生成并维护 STRM 媒体库
- “RE0资源搜索”使用 MoviePilot 内置浏览器登录 RE0，按 TMDB 搜索资源，并在用户逐条确认积分后解锁 115、磁力或 ED2K 链接

- “PanSou聚合搜索”接入自建 PanSou 与 BT4G，支持原生搜索、浏览器完成验证后带回结果，以及可选115媒体库导入

RE0 插件只负责资源获取，不复制腾讯文档插件的解析和媒体库代码。用户明确点击“保存到媒体库”时，才会把已解锁链接交给腾讯文档插件现有的自选导入入口；没有安装腾讯文档插件时仍可独立搜索、解锁和打开链接

**0.13.0** 修复网关鉴权、后台死锁、同名文件覆盖、增量同步漏行和刮削/下载恢复问题。新增浏览器 302 直链下载：默认不创建下载器任务；原生搜索卡片点击需要安装[配套浏览器脚本或前端补丁](integrations/README.md)，未安装时可从搜索结果的 `ⓘ` 详情页点击浏览器下载。磁力和 ED2K 需要先在 115 云端完成离线，视频正文不经过 NAS。

新生成文件带资源身份以避免覆盖，清空只删除有归属记录且未被用户修改的文件。升级说明见[0.13.0 发布说明](docs/tencentdoc115library/0.13.0.md)。

## 安装

在 MoviePilot 的“设置 → 插件 → 插件仓库”中添加：

```text
https://github.com/CelestialRipple/115-doc/
```

刷新插件市场后可分别安装“腾讯文档115媒体库”、“RE0资源搜索”和“PanSou聚合搜索”

- 腾讯文档插件的完整配置、路径映射和测试方法见[使用说明](docs/tencentdoc115library/README.md)
- RE0 插件的功能边界和配置说明见[RE0资源搜索](docs/re0search/README.md)

- PanSou 与 BT4G 的配置、手动验证和限制见[PanSou聚合搜索](docs/pansouaggregate/README.md)

## 安全说明

腾讯文档 Token、115 Cookie、播放密钥和 RE0 登录凭据只保存在 MoviePilot 的插件配置中，不应提交到本仓库。建议定期更新访问令牌，并为 MoviePilot 管理界面启用安全的访问控制

# 115-doc

MoviePilot V2/V3 插件“腾讯文档115媒体库”。插件可将多个腾讯文档或用户单条/批量添加的 115 分享、磁力和 ED2K 资源同步到本地目录，使用 MoviePilot 识别和刮削并生成 STRM。115 分享在播放或下载时直接获取临时直链；磁力和 ED2K 则在首次播放或下载时才离线到 115 插件专属临时目录，完成后返回 302，并在最后访问至少 24 小时后精确清理。支持最新版 V3 异步原生检索，并可从搜索结果直接选择直属输出文件夹及电影、剧集或自动识别后保存尚未入库的资源；另有手动链接入口。还支持混合表自动纠正电影/电视剧分类、未识别资源降级生成 STRM、并行刮削、跨工作表复用元数据、按工作表分开目录、现有目录免刮削迁移，以及后台任务暂停与恢复。

## 安装

在 MoviePilot 的“设置 → 插件 → 插件仓库”中添加：

```text
https://github.com/CelestialRipple/115-doc/
```

刷新插件市场并安装“腾讯文档115媒体库”。完整配置、Docker 路径映射和测试方法见[使用说明](docs/tencentdoc115library/README.md)。

## 安全说明

腾讯文档 Token、115 Cookie 和播放密钥只保存在 MoviePilot 的插件配置中，不应提交到本仓库。建议定期更新访问令牌，并为 MoviePilot 管理界面启用安全的访问控制。
